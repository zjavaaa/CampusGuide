# Przewodnik po kampusie

Projekt na laboratorium Zarządzania Projektami Informatycznymi, WSB Merito. Aplikacja pokazuje trzy punkty przykładowego kampusu. Po wybraniu budynku na mapie lub z listy pojawiają się jego lokalizacja i opis.

## Środowisko

Unity **2022.3.5f1 LTS**, szablon **3D (Built-In)**. Docelowo Windows x86-64, standardowe wsparcie kompilacji Windows, backend Mono.

## Uruchomienie

1. Sklonuj repozytorium i dodaj jego główny katalog przez **Unity Hub → Projects → Add project from disk**.
2. Otwórz projekt w podanej wersji Unity, a po imporcie otwórz scenę **Assets/Scenes/CampusGuide.unity** i naciśnij **Play**.
3. Aby zbudować aplikację, użyj **File → Build Settings**, wybierz Windows x86-64 i zapisz build w **Builds/Windows**. Uruchom **CampusGuide.exe** z tego katalogu.
